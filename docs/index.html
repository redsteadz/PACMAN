PACMAN

A Pac-Man inspired arcade game in C++ with raylib. Four ghosts with the classic chase, scatter and frightened behaviours, power pellets, a map editor, and a generous amount of particle effects.

Download

Pre-built binaries for both platforms. Each archive contains the game and every asset it needs, so there is nothing else to install.

Windows

64-bit Windows 10 or newer. The executable is statically linked, so there are no extra runtime DLLs to keep alongside it.

Built on Ubuntu and portable across modern glibc distributions. raylib is linked statically, so the only requirements are OpenGL and the usual X11 libraries.

Running it? Both archives unpack into a single folder with Pacman and assets/ side by side. Run the game from that folder and keep the two together — the game loads its textures, sounds and map file relative to its working directory.

How to play

Clear the maze, grab the power pellets, and keep the ghosts off your tail.

Controls

InputAction
W A S DChange direction
SpaceMovement boost (limited use)
Pause buttonPause or resume the game
Edit buttonOpen the map editor

Map editor

The editor opens from the in-game UI. Paint tiles with the left mouse button, erase with the right, then use the save and load buttons to store your layout as a .bin file in the assets folder and load it again later.

Saved maps are read by name from the text box next to the save button, so keep names short and file-system safe.

Build it yourself

All you need is CMake, a C++ compiler and raylib 5.x. 

# Linux (Arch / CachyOS)
sudo pacman -S base-devel cmake raylib

# Linux (Debian / Ubuntu)
sudo apt install build-essential cmake libraylib-dev

# macOS
brew install cmake raylib

git clone https://github.com/redsteadz/PACMAN.git
cd PACMAN
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/bin/Pacman

No raylib installed? Let CMake fetch and compile it for you: 

cmake -S . -B build -DPACMAN_USE_BUNDLED_RAYLIB=ON
cmake --build build -j
Cross-compiling for Windows? The repository ships a MinGW-w64 toolchain file at cmake/toolchain-mingw-x86_64.cmake. Add -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-mingw-x86_64.cmake -DPACMAN_STATIC_RUNTIME=ON to get a standalone .exe.
